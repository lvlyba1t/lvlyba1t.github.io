# The NSK portfolio

Static portfolio website published with GitHub Pages.

- Edit contact destinations and the project list in `content.js`.
- Change the shared line thickness via `--rule` in `style.css` (currently `3px`, provisional).
- Horizon headings are vector SVG artwork. Ropa Sans is bundled under its accompanying SIL Open Font License.
- Project imagery and the contact claim are working content and can be replaced separately from the page layout.

No build step is needed. Serve the repository root with any static HTTP server.
